\section{Implementation Validation}
\label{app:validation}

Two of the checks below, the brute-force comparison and the free-energy test, test the
derivation; the rest test the software. All of them run the
real code path on small tensors, in double precision wherever a precision claim is made.

\paragraph{Exact readout against brute force.}
On one slot the graph is a star centred on $\Zv{t}$, hence a tree, so \Cref{eq:exact-readout}
must equal the marginal of the slot joint computed by enumeration. We enumerate
$p(\Wv{t}, \Zv{t}, \Hv{t}{1..\nchan} \mid z_{\prefix{t}})$ over every configuration, written
from the raw parameters with loops and calling no method of the model, and marginalise to
$p(\Wv{t})$. The result agrees with the closed form to $6.7\times10^{-16}$ in log-probability
($|\Vocab|=6$, $\nlab=4$, $\nchan=2$, $|\Dep{t}|=5$, float64). This checks the factorisation
itself, not only its implementation. The factored variant at $K=2$ agrees with an enumeration
over $(\Wv{t}, \Zv{t}^{(1)}, \Zv{t}^{(2)}, \Hv{t}{1..4})$ to $10^{-10}$. A second reference
rebuilds the contracted arc scores by hand; it pins the assignment of channels to components,
which the enumeration alone cannot see.

\paragraph{Global variable and readout scan.}
The same enumeration with a global variable folded in as one more leaf off $\Zv{t}$ agrees with
\Cref{eq:global-readout}, and the \texttt{logcumsumexp} scan of \Cref{eq:mu-scan} agrees with
slot-by-slot assembly for $\clip\in\{0,1,2,4,9\}$; both are asserted at $10^{-12}$.

\paragraph{Free energy, with a mutation test.}
The per-slot free energy $\Free_t$ of \Cref{eq:slot-free-energy} must not increase along the
inner loop, since each update is its centred gradient step. Over eleven block updates it shows
$0$ increases and a total decrease of $5.68\times10^{-3}$. This is the check that tests the
update equations: a sign error in the head update would pass every shape, normalisation and
causality check. With the head message negated, the same eleven updates give $11$ increases, the
largest $6.5\times10^{-2}$, and the free energy rises overall.

\paragraph{Causality.}
Changing the token at position $t{+}1$ leaves the logits at every slot $\le t$ bitwise
unchanged, under both readouts and all three head temperatures. Over the six combinations the
maximum absolute difference is $0$, checked by equality and not by a tolerance. The check runs on
CPU with a fixed seed, because non-deterministic reductions on a GPU can change the last bit of
correct code.

\paragraph{Frozen prefix in the gradient.}
The prefix is frozen in the forward pass but not detached in the backward pass
(\Cref{sec:chain}). A test on a detached tensor would pass trivially, so the prefix beliefs are
kept as attached leaves. After backpropagating the loss at slot $t$,
$\partial \mathcal{L}_t / \partial \qbar{j}$ is exactly zero for $j \ge t$ and non-zero for
$j < t$.

\paragraph{Tying.}
$\Sfac$ appears once in the parameter list, and the same tensor object serves as the unary and
as the output factor (\Cref{sec:output}). The test checks identity, not equality: two tensors
initialised alike and updated by the same gradient would be equal but would form a different
model.

\paragraph{Factored labels reduce to the flat model.}
With $K=1$ the factored decoder must be the model of \Cref{sec:chain}. A flat state dict loads
into it with no missing or unexpected key, and the logits agree to $6.9\times10^{-18}$ across
both readouts and both arc-score parameterisations in float64. The residual is floating-point
reassociation from the extra component axis.

\paragraph{Normalisation and the worked example.}
Every posterior sums to one along its variable axis at every iteration (maximum deviation
$1.2\times10^{-7}$ in float32), the logits are finite, and a single batch can be overfitted to
near-zero loss. The worked example of \Cref{app:worked-example} matches an independently derived
reference digit for digit.

All tables and figures are generated by one script from the run records, which store each run's
configuration, validation and diagnostic traces, device and code version.
